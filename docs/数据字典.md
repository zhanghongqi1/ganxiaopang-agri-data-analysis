# ganxiaopang_db 数据字典

> 全部为**模拟数据**（Faker + 业务规则，固定种子生成）。`data/sample/` 提供每表 ≤1000 行样例。

## 维表

### dim_sku — 商品 SKU（约 2,100 行）

| 字段 | 类型 | 说明 |
|---|---|---|
| sku_id | INT PK | 主键 |
| sku_code | VARCHAR(20) | 编码，如 GXP-DF-0001（DF=定西宽粉等品类前缀） |
| sku_name | VARCHAR(100) | 商品名 |
| category_l1 | VARCHAR(20) | 一级大类，共 11 个 |
| category_l2 | VARCHAR(50) | 二级类目，共 68 个 |
| brand_series | VARCHAR(30) | 品牌系列（甘小胖/胖娃优选/陇原农特/小胖甄选等） |
| spec | VARCHAR(50) | 规格 |
| unit | VARCHAR(10) | 单位（kg/袋/箱/盒/瓶） |
| cost_price | DECIMAL(10,2) | 成本价 |
| retail_price | DECIMAL(10,2) | 零售价 |
| gross_margin_rate | DECIMAL(5,4) | 毛利率（清洗后校验 ∈(0,0.85]） |
| supplier_id | INT FK | 供应商标 dim_suppliers |
| origin | VARCHAR(30) | 产地（甘肃县域） |
| is_self_operated | TINYINT | 1=自营工厂产品（定西宽粉系），0=外采 |
| shelf_date | DATE | 上架日期 |
| status | VARCHAR(10) | 在售/清仓/下架 |

### dim_users — 电商用户（约 9,000 行）

| 字段 | 类型 | 说明 |
|---|---|---|
| user_id | INT PK | 主键 |
| nickname | VARCHAR(50) | 昵称（Faker zh_CN） |
| gender | VARCHAR(2) | 男/女（原始层含少量异常值，清洗处理） |
| age | INT | 18-65（原始层含超界异常值） |
| province | VARCHAR(20) | 省份（原始层含缺失/格式不一） |
| city_tier | TINYINT | 城市线级 1-5 |
| register_date | DATE | 注册日期 |
| source | VARCHAR(20) | 渠道：直播间/短视频橱窗/商城搜索/老客推荐 |
| is_fan | TINYINT | 是否抖音粉丝 |
| member_level | VARCHAR(10) | 普通/银卡/金卡/黑卡 |

### dim_suppliers — 供应商（60 行）

supplier_id PK / supplier_name / supplier_type（农户/合作社/工厂）/ region / coop_years 合作年限 / annual_supply_tons 年供货量（吨）

### dim_stores — 线下门店（4 行）

| 字段 | 说明 |
|---|---|
| store_id PK | 门店ID |
| store_name | 甘小胖宽粉麻辣烫（陇西店/通渭店/平凉店/静宁店） |
| city | 陇西/通渭/平凉/静宁 |
| open_date | 开业日期（2023 年 Q1） |
| area_sqm | 营业面积（㎡） |
| rent_monthly | 月租金 |
| staff_cnt | 员工数 |
| seats | 座位数 |
| initial_investment | 初始投入（装修+设备，万元） |

### dim_warehouses — 仓库（2 行）

warehouse_id PK / warehouse_name（甘小胖主仓·定西 2400㎡ / 兰州中转仓 1000㎡）/ area_sqm / location

## 事实表

### fact_live_sessions — 直播场次（624 行，2024-2025 每周约 6 场）

session_id PK / live_date / start_time / duration_min（55-120 分钟）/ anchor（主播小胖(负责人)/主播小陇/主播阿甘/主播小花）/ theme（助农专场/宽粉工厂专场/常态化带货/节庆大促）/ sku_cnt / total_exposure / total_enter / total_stay（停留>30s）/ total_interact / total_order_placed / total_paid / gmv / new_followers / is_festival / **main_category（本场主推品类 L1，用于品类内容成本归集）**

### fact_live_minute_traffic — 直播分钟级流量（约 40,000 行）

id PK / session_id FK / minute_index（开播起第几分钟）/ viewers_online 在线人数 / exposure_delta 曝光增量 / enter_delta 进入增量 / comment_cnt 评论数 / like_cnt 点赞数 / follow_delta 涨粉 / order_cnt 下单数 / pay_user_cnt 付款人数

### fact_orders — 电商订单（约 22,000 行）

| 字段 | 说明 |
|---|---|
| order_id PK | 订单号 GXP+日期+序号 |
| user_id FK | 用户 |
| order_time | 下单时间（受直播场次时间驱动） |
| channel | 直播间/短视频橱窗/商城搜索 |
| session_id FK | 关联直播场次（直播间渠道必填，其余 NULL） |
| order_status | 已付款/已发货/已完成/已取消/已退款（原始层含非法状态值，清洗处理） |
| item_cnt | 商品件数 |
| pay_amount | 支付金额（元） |
| discount_amount | 优惠金额 |
| freight | 运费 |
| province / city | 收货地（原始层含缺失，清洗处理） |

### fact_order_items — 订单明细（约 33,000 行）

id PK / order_id FK / sku_id FK / quantity 数量 / unit_price 成交单价 / cost_price 时点成本 / promotion_type（无/限时秒杀/满减/助农补贴/组合装）

### fact_b2b_orders — B2B 供货订单（约 600 行）

b2b_id PK / customer_name（火锅餐饮/商超/特产店/加盟门店，如"北家姓火锅供应链"）/ customer_type / order_date / sku_id FK（定西宽粉系为主）/ quantity_kg / unit_price / amount

### fact_purchases — 采购单（约 750 行）& fact_purchase_items — 采购明细（约 1,500 行）

采购单：purchase_id PK / supplier_id FK / purchase_date / arrival_date / total_amount / quality_grade（A1/A2/A3 感官分级，呼应"色泽爆汁 Q 弹"标准）/ status（到货/在途/已入库）
明细：id PK / purchase_id FK / sku_id FK / quantity_kg / unit_cost / amount / quality_grade / **rejected_kg（验收不合格量，采购损耗口径）**

### fact_warehouse_stock — 库存双周快照（约 1,840 行）

id PK / snapshot_date（双周）/ warehouse_id FK / sku_id FK（20 个核心 SKU）/ stock_kg / in_transit_kg / **avg_daily_outflow_kg（日均出库量，库存周转天数 = stock_kg ÷ avg_daily_outflow_kg）** / avg_days_in_stock 库龄（天）

### fact_deliveries — 配送单（约 3,600 行）

| 字段 | 说明 |
|---|---|
| delivery_id PK | 配送单号 |
| biz_type | 电商订单/门店补货/B2B供货 |
| ref_id | 关联业务单号（订单号/门店ID/B2B单号） |
| from_warehouse FK | 发货仓 |
| to_region | 目的省份 |
| ship_date / arrive_date | 发货/签收日期 |
| lead_time_days | 履约时效（天） |
| box_cnt / weight_kg | 箱数/重量 |
| loss_kg | 配送损耗（kg） |
| freight_cost | 运费（元） |
| delivery_mode | 旧模式（分散直发+统配） / 新模式（集中仓储+分级配送，2025 年起试点） |

### fact_store_sales_daily — 门店日销售（约 8,700 行，店×日×品类）

id PK / store_id FK / sale_date / category（宽粉麻辣烫/特色小吃/饮品）/ order_cnt 订单数 / customer_cnt 到店客数 / foot_traffic 进店人次 / sales_amount 销售额 / discount_amount 优惠额

## 实体关系（简）

```
dim_users 1─n fact_orders 1─n fact_order_items n─1 dim_sku n─1 dim_suppliers
fact_live_sessions 1─n fact_live_minute_traffic
fact_live_sessions 1─n fact_orders（直播间渠道）
dim_sku 1─n fact_purchases→fact_purchase_items / fact_warehouse_stock / fact_b2b_orders
fact_deliveries.ref_id → fact_orders | dim_stores | fact_b2b_orders
dim_stores 1─n fact_store_sales_daily
```
